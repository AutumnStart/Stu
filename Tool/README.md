# 关键用户行为节点分析提取工具

## 功能介绍

此工具用于自动从留香珠产品的素材分析报告中提取"关键用户行为节点分析"数据，并将其追加到AI分析结果文件中对应的素材条目中。

主要功能包括：

1. **提取素材名称**：从AI分析结果文件中提取每个素材的名称和位置信息
2. **查找对应JSON文件**：根据素材名称在指定目录中查找对应的JSON分析报告文件
3. **提取行为分析数据**：从JSON文件中提取"关键用户行为节点分析"部分
4. **更新AI分析结果**：将提取的分析数据追加到AI分析结果文件中
5. **清理重复数据**：检测并清理文件中可能存在的重复行为分析数据

## 使用方法

### 通过批处理文件运行（推荐）

1. 双击运行 `extract_behavior_analysis.bat` 文件
2. 脚本将自动执行，并在控制台显示执行进度和结果
3. 执行完成后，结果将保存在 `json/素材数据分析/AI分析结果.txt` 文件中

### 通过命令行运行

```bash
# 在项目根目录下执行
cd Tool
python extract_behavior_analysis.py
```

## 文件结构

- `extract_behavior_analysis.py` - 主程序脚本
- `extract_behavior_analysis.bat` - Windows批处理启动文件
- `json/素材数据分析/AI分析结果.txt` - 输入和输出文件
- `json/留香珠/` - 包含素材分析报告的JSON文件目录

## 功能说明

1. **素材名称提取**：使用正则表达式从AI分析结果文件中提取素材名称和位置信息
2. **JSON文件查找**：根据素材名称构建对应的JSON文件名，并在指定目录中查找
3. **行为分析提取**：从JSON文件中读取"关键用户行为节点分析"字段的内容
4. **AI分析结果更新**：将提取的行为分析数据追加到AI分析结果文件中对应素材的末尾
5. **重复数据清理**：检测并删除文件中可能存在的重复行为分析数据

## 注意事项

- 如果某个素材已经包含关键用户行为节点分析，脚本将跳过该素材
- 如果找不到对应的JSON文件，脚本会尝试模糊匹配
- 脚本会自动检测并清理重复的行为分析数据
